==== UML basics and class diagrams (slides 10-23) ====
11) UML is best described as:
A) a programming language
B) an integration of earlier OO notations and a de facto standard for OO modeling
C) a database engine
D) a testing framework
Answer: B

12) The UML diagram-types slide divides diagrams into:
A) static and dynamic only
B) structural and behavioral
C) logical and physical only
D) compile-time and run-time only
Answer: B
(structural: class diagram, object diagram, component diagram, deployment diagram, package diagram)
(behavioral: sequence diagram, activity diagram, state machine diagram, UC diagram)

13) Which of the following is a structural diagram?
A) Sequence diagram
B) Activity diagram
C) Class diagram
D) State machine diagram
Answer: C

14) Which of the following is a behavioral diagram?
A) Package diagram
B) Component diagram
C) Object diagram
D) Sequence diagram
Answer: D

15) A UML class is usually drawn as:
A) a circle with arrows
B) a rectangle with separate compartments
C) a diamond
D) a cloud
Answer: B

16) The only required tag in the graphical representation of a class is the:
A) attribute list
B) operation list
C) class name
D) stereotype
Answer: C

17) Which is the correct UML attribute notation?
A) String = name
B) name -> String
C) name : String
D) String : name()
Answer: C

18) A derived attribute is marked with:
A) +
B) *
C) /
D) #
Answer: C

19) Which visibility symbol means private?
A) +
B) #
C) /
D) -
Answer: D

20) Class operations in UML:
A) appear in the second compartment only
B) describe class behavior and appear in the third compartment
C) cannot have names
D) cannot have parameters
Answer: B
(class operations: method)

21) An operation signature may include:
A) only the operation name
B) only the return type
C) parameter names/types/defaults and possibly a return type
D) only visibility
Answer: C
(listing the name, type, and default value of all parameters, and, in the case of functions, a return type)

22) A class responsibility is:
A) the memory size of the class
B) a contract or obligation of a class to perform a particular service
C) the class color
D) a replacement for attributes
Answer: B

23) In the Employee class example, which of the following is an operation?
A) salary
B) status
C) join()
D) department
Answer: C

24) When drawing a class in UML:
A) you must always show every attribute and every operation
B) you needn't show attributes and operations in every diagram
C) only attributes can be omitted
D) only operations can be omitted
Answer: B
(vì UML chỉ show ý tưởng và vì required only class name)

A) one class inherits from another
