Single Responsibility Principle (SRP)
13. The Single Responsibility Principle states:

A) A class should have only one method
B) A class should have only one reason to change
C) A class should only have private variables
D) A class should never use inheritance
Answer: B
(vì 1 lớp chỉ nên làm 1 nhiệm vụ, nếu nhiệm vụ thay đổi thì chỉ có 1 reason)

14. The slide says SRP encourages developers to strive for:

A) coupling
B) cohesion
C) abstraction leakage
D) redundancy
Answer: B

15. In the slide, cohesion is described as:

A) the number of classes in a package
B) the functional relatedness of the elements of a module
C) how many interfaces a class implements
D) the amount of code reuse
Answer: B

16. In the Book example, which responsibility properly belongs inside the Book class?

A) printing text to console
B) writing to another medium

D) formatting printer output
Answer: C


18. Why is putting both text behavior and printing behavior in Book a violation of SRP?

A) derived classes must be smaller than base classes
B) derived classes must be substitutable for their base classes

Interface Segregation Principle (ISP)

(thay vì tạo 1 interface khổng lồ, thì nên tách thành interface nhỏ hơn đúng với mục đích sử dụng)

Dependency Inversion Principle (DIP)
39. The Dependency Inversion Principle says:

A) depend on concrete classes, not abstractions
B) depend on abstractions, not concrete classes
C) high-level components should control all low-level details directly
D) abstractions should depend on concrete classes
Answer: B
(không phụ thuộc vào class cụ thể, nên phụ thuộc vào abstract class/interface)

40. According to the slide, high-level components should not depend on:

A) low-level components directly
