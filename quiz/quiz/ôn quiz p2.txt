Part 1 – Multiple Choice & True/False (1 point each)
1. Which of the following is a framework activity?

A. Risk management
B. Software configuration management
C. Communication
D. Technical review
=> C

2. Which of the following is an umbrella activity?

A. Modeling
B. Construction
C. Deployment
D. Risk management
=> D

3. The generic process framework includes:

A. Requirements, Code, Maintain
B. Communication, Planning, Modeling, Construction, Deployment

=> B

4. A task set defines:

A. A lifecycle model
B. Work tasks, work products, and QA filters
C. Only risk activities
D. Only coding standards
=> B

5. Plan-driven processes are characterized by:

A. Minimal documentation
B. Heavy documentation and advance planning
C. No formal phases
D. Continuous informal communication only
=> B

A. Inception
B. Elaboration
